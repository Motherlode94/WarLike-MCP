WarLike // MCP

Ouvrir Engine

Extension d'intégration MCP pour l'éditeur Web WarLike. WarLike Server fournit l'authentification technique des commandes et la file persistante Cloudflare D1. Ce site ne contrôle pas automatiquement tes onglets.

Connexion sécurisée

  1. Configurer les secrets WARLIKE_MCP_TOKEN et WARLIKE_MCP_EDITOR_TOKEN côté WarLike Server (deux valeurs différentes, au moins 32 caractères), et activer le binding D1 existant.
  2. Déployer les PR du Server, d'Engine et de ce dépôt, après validation CI.
  3. Dans WarLike Engine, cliquer sur ⬡ MCP, saisir la clé d'éditeur, choisir Lecture seule ou Modification, puis Connecter.
  4. Dans ton client MCP, configurer l'URL HTTPS https://warlike-mcp.pages.dev/mcp avec Authorization: Bearer <WARLIKE_MCP_TOKEN>.
  5. Le client appelle tools/list, puis tools/call. Les commandes attendent un résultat que l'onglet Engine autorisé retourne via Server. Utiliser warlike_list_sessions, copier l'ID de l'onglet souhaité, puis transmettre sessionId pour chaque outil.
Les commandes ne peuvent pas accéder aux autres sites, au disque ni au système d'exploitation. Aucun script arbitraire ni donnée de compte n'est exposé. Ne jamais placer une clé d'accès dans le dépôt ou dans une URL.

Vérifier la connexion MCP

Ce diagnostic appelle uniquement tools/list. La clé saisie n'est pas enregistrée, ni envoyée ailleurs qu'au relais WarLike Server.

Aucun diagnostic lancé.

Une fois connecté à Engine, copie l'ID session affiché par ⬡ MCP. Les outils requièrent ce sessionId explicite pour ne jamais modifier le mauvais projet.

Composants et GameObjects

Fonctions initiales : énumérer les objets, sélectionner, modifier Transform, ajouter un composant disponible, lire et changer une propriété scalaire. Les Prefabs, Assets et Extensions restent distincts des Components.

Le contrôle distant exige une autorisation de l'onglet, et toute modification est refusée pendant Play. Le serveur doit être réellement déployé et connecté pour exécuter ces commandes.
